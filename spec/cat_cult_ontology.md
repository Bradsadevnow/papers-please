## Epoch 0 under the new premise

`epoch_0_product_atlas.md`'s mechanic doesn't change — the player still types anything, Gloss still institutionalizes it unconditionally (Design Rule #3: "if they typed 'hello,' they are the CEO of a hello-themed company"). What changes is the *world* doing the reframing. The existing worked example in that doc:

> Player input: *a to-do list app*
> Gloss response: "This is an exciting development. You have successfully described something." -> *TaskDrift: Ambient Productivity Substrate for knowledge workers undergoing voluntary cognitive deferral*

Under the cat-cult premise, the same mundane input gets reframed through the same institutional certainty, just now soaked in the actual ontology:

> Player input: *a to-do list app*
> Gloss response: "This is an exciting development. You have successfully described something." -> *TaskDrift: Warmth-Adjacent Productivity Substrate — tracks task completion via ambient lap-occupancy correlation. Category: Feline-Aligned Workflow Tooling.*

## Demo-video golden path (locked 2026-07-01, replaces "parking meter that detects emotional abandonment")

`demo_roadmap.md`/`demo_video_structure.md` locked a specific input for filming purposes only — not a mechanic-level lock (see Epoch 0 note above). Confirmed by Brad and applied to both files plus `gloss_context_schema.md`'s example payloads:

**Player types:** *"a keyboard that requires cat approval before accepting input"*

Week 1's Friction Spark exchange produces the doctrine payoff: **Keyboard Access Policy v17.4** — "The Cat's occupancy of designated input hardware constitutes an approved override event, requiring no further authorization." Keeps the "player says something small and true, the institution makes it inevitable" mechanic exactly as designed, and ties Epoch 0's founding product directly to the Layer 2 immutable law rather than an arbitrary absurd pairing.
